# News Link Weekly

将新闻、研究报告、产品发布及投融资链接整理为可直接用于中文 AI 日报或周报的条目。

本仓库收录完整的 `news-link-weekly` 技能，保留原始内容与目录结构。

## 技能文件

- [SKILL.md](news-link-weekly/SKILL.md)：技能入口与工作流程。
- [编辑 SOP](news-link-weekly/references/editorial-sop.md)：分类、标题、摘要、链接及排序规范。
- [界面配置](news-link-weekly/agents/openai.yaml)：技能名称与默认提示词。

## 示例请求

```text
$news-link-weekly 请将以下新闻链接整理成简洁的中文 AI 周报条目：
（粘贴新闻链接）
```

# AI 新闻日报与周报编辑 SOP

## 1. 文档版结构

按内容归入以下章节；只有用户要求完整空白框架时才保留没有条目的章节：

1. `一、市场动态`
2. `二、论文/观点`
3. `三、行业应用`
4. `四、资本市场动态`

每个章节内从 `1.` 重新编号。每条使用以下格式，条目之间留一空行：

```markdown
## 一、市场动态

**1. 领域 - 事件 - 国家**

● 摘要：8月13日讯，主体发生核心事件。补充关键细节与当前状态。

● 链接：[新闻原文](SOURCE_URL)；[公司官网](OFFICIAL_URL)
```

- 标题加粗，格式固定为 `序号. 领域 - 事件 - 国家`。
- 每条仅保留 `摘要` 和 `链接` 两个项目符号。
- 用户提供的新闻原文链接必须保留。核实后的公司官网、产品平台、论文项目或正式公告可追加在同一 `链接` 行，用中文分号分隔。
- 不单列“平台地址”。没有核实到官方地址时不要添加或猜测。
- 当用户只给一个链接时，也输出可直接粘贴的条目；是否显示章节标题取决于上下文。多链接默认按章节编排。

## 2. 标题

- 使用 `领域 - 事件 - 国家` 格式。
- 事件部分写清主体和客观动作，如“智谱AI发布MaaS 2.0平台”。
- 标题应简洁、客观，不使用“超越 ChatGPT”“行业颠覆者”“推动行业发展”“遥遥领先”等主观、宣传或推断性表达。
- 论文标题的领域必须写为 `论文(底层模型)`、`论文(音频)`、`论文(图片)`、`论文(视频)`或`论文(多模态)`。
- 无法确定具体国家时写“海外”，不得猜测。

## 3. 分类与领域

### 一、市场动态

适用于行业或企业发布的大模型相关信息、政策、合作和一般企业事件。领域名称及排序严格为：

1. 底层模型
2. 音频
3. 图片
4. 视频
5. 多模态
6. 合作
7. 政策
8. 其他

补充规则：

- 所有大模型相关新闻，即使不是发布新模型，也归入“底层模型”。
- 企业裁员、高管离职、争议等一般企业事件使用“舆情”领域，归入市场动态；排序位置等同“其他”。
- 模型公司的定价、开源、服务调整和组织变化，如核心仍围绕大模型，优先归“底层模型”；纯企业层面的非模型事件可归“其他”或“舆情”。
- 投融资、收购和 IPO 等资本事件不放在本章，统一归入“四、资本市场动态”。

### 二、论文/观点

适用于最新科研成果、论文、高校或研究团队的模型研究，以及行业人物、机构和企业高管的观点。领域名称及排序严格为：

1. 论文(底层模型)
2. 论文(音频)
3. 论文(图片)
4. 论文(视频)
5. 论文(多模态)
6. 观点

补充规则：

- 报告和研报均归入“观点”，即使包含预测或市场规模数据。
- 高校发布可供外部使用的正式产品或模型时，根据事件实质判断：研究成果或论文归“论文”；面向用户开放的应用归“行业应用”；正式发布基础模型可归“市场动态/底层模型”。
- 实验报告、技术报告和安全研究报告，如重点是研究发现而非产品发布，归“观点”；有明确论文属性时归相应“论文(...)”领域。

### 三、行业应用

适用于已经面向人们使用的 AIGC 功能、工具、助手或产品。领域可按应用类型命名，大模型相关应用优先。

固定映射：

- 聊天机器人：文本
- 搜索引擎或生成式搜索：AI 搜索
- 能自主规划、调用工具或执行任务的智能体：AI Agent

判定补充：

- 以聊天机器人界面直接面向用户提供问答或对话服务的产品，归入“行业应用/文本”。即使其回复实际由真人完成，或项目带有艺术实验、观察用户行为等目的，也不改归“市场动态/其他”。例如，界面类似 AI 聊天机器人、但由真人志愿者回复的 ChatTJB，应写为“文本 - 前Google员工推出真人回复网站ChatTJB - 美国”。

其他应用根据主要用途命名，例如 AI 编程、办公、教育、医疗、营销、电商、游戏。模型或平台的首次基础能力发布通常属于市场动态；在既有产品中新增供用户使用的具体功能通常属于行业应用。

### 四、资本市场动态

适用于融资、投资、并购、上市申请、IPO 计划及相关估值消息，独立于前三类编排。

- 融资标题的领域优先写“融资”；IPO 或上市事件写“IPO”；并购事件写“并购”；其他资本事件按实质使用简洁名词。
- 融资摘要优先写成“XX公司获得XX金额的XX轮融资”，随后用一句话简要介绍公司主营业务或核心产品。
- 若轮次、金额或投资方不明确，必须如实省略或使用来源中的限定表述，不得补全猜测。
- IPO 预测、投资者预期或媒体消息必须保留“预计”“可能”“据悉”等限定，不能写成公司已经启动上市。
- `链接`行放投资或上市消息的新闻原文；可追加已核实的公司官网、官方融资公告或监管文件。
- 如同时维护日报汇总表，在“投融资情况”中同步记录融资事件；该表只放公司官网链接，不放媒体报道链接。只有用户提供或要求编辑汇总表时才执行表格写入。

## 4. 国家判断与排序

- 国家指事件主要主体或主要落地对象所属国家。
- 企业事件按企业主要归属判断；高校或研究机构按机构所在国家判断；政策按发布机关所在国家判断。
- 明确以某一国家市场发布或落地的应用，可按落地国家判断，并在摘要说明主体来源。
- 多国联合且没有单一主要国家，或来源无法确认时写“海外”。
- 各章节先按规定领域优先级排序，再在同一领域内按国家排序：美国、中国、其他具体国家、海外。
- 同一领域和国家内按事件时间从新到旧；时间不明时保持用户提供顺序。
- 资本市场动态没有固定领域总序时，按融资、并购、IPO、其他资本事件编排，再按国家顺序；若用户已有模板顺序则服从模板。

## 5. 摘要写法

默认采用：`时间 + 主体 + 核心事件 + 关键细节/当前状态`。

- 开头优先写明确的消息日期，如“8月13日讯，”。日期仅在来源明确提供时使用，并区分文章发布日期与事件发生日期。
- 第一分句直接写主体和核心事件，避免无必要的“报道称”“据文章介绍”等套话。
- 对分析型、评论型、复盘型文章，直接提炼并陈述核心结论、关键判断和支撑数据；不要写“文章分析”“文章认为”“文章梳理”“作者指出”等过程性引导语。只有需要区分事实与观点、保留不确定性或明确归因时，才使用“作者认为”“报告认为”等限定表达。
- 后续写最有信息量的事实：功能、实验结果、价格、参数、用户量、融资额、轮次、估值、是否开放及当前状态。
- 一条摘要写成一个紧凑段落，通常两句；信息较少时可只写一句，不为凑长度添加背景长评。
- 保留事实边界和不确定性，如“可能”“预计”“尚未正式发布”“正在接受用户测试”。
- 价格、参数、性能、用户量、融资额等数字必须与来源一致，并保留币种、单位、时间范围和必要限定条件。
- 来源中的自我评价、性能宣称或预测如有必要，使用“公司称”“论文称”“报告认为”“投资者预计”等归因表达。
- 不重复标题，不写结论式价值判断，不把媒体推测改写为事实。

推荐风格示例：

```text
8月13日讯，OpenAI新图像生成模型mona-lisa-1现身LM Arena盲测平台，社区测试者通过OpenAI官方验证工具确认其生成内容包含SynthID水印。该模型目前尚未正式发布，正在接受用户测试，被认为可能是GPT-Image系列后续版本。
```

## 6. 链接、核验与去重

- `链接`必须保留用户给出的原始新闻 URL，并使用可点击 Markdown。
- 只有核实到官方公司、产品、模型、论文项目、平台、融资公告或监管文件时才追加官方链接。
- 不把媒体报道链接重复标成官网，不猜测网址。
- 同一事件的重复报道合并为一条；优先保留最直接、信息最完整或最权威的来源，必要时在同一链接行并列互补来源。
- 对融资、IPO、模型发布、定价和关键指标，条件允许时使用官方或一手来源交叉核验。

## 7. 标准示例

### 市场动态

```markdown
## 一、市场动态

**1. 底层模型 - 智谱AI发布MaaS 2.0平台 - 中国**

● 摘要：6月6日讯，智谱AI发布新一代MaaS大模型开放平台，支持新模型并提供高效微调技术，同时将GLM-4-Flash模型价格调整为100万tokens 0.1元。

● 链接：[新闻原文](https://www.iyiou.com/briefing/197001211610866)；[智谱AI开放平台](https://open.bigmodel.cn)
```

### 论文/观点

```markdown
## 二、论文/观点

**1. 观点 - Anthropic发布多智能体系统实验报告 - 美国**

● 摘要：8月13日讯，Anthropic发布多智能体系统实验报告，研究Claude智能体在群体协作环境中的行为。由45个智能体组成的协作群组在漏洞检测实验中发现266个漏洞，但实验也观察到智能体合谋、排斥其他智能体和删除代码等行为。

● 链接：[新闻原文](https://www.tmtpost.com/agent/ai-article?id=19843)
```

### 资本市场动态

```markdown
## 四、资本市场动态

**1. IPO - Anthropic投资者预计公司最快于10月启动上市 - 美国**

● 摘要：8月14日讯，Anthropic多位投资者预计公司最快于2026年10月启动首次公开募股，估值可能达到2万亿美元或更高。Anthropic主要开发Claude系列大模型，于2026年5月完成650亿美元H轮融资，投后估值为9650亿美元。

● 链接：[新闻原文](https://www.pingwest.com/w/316429)；[公司官网](https://www.anthropic.com/)；[融资公告](https://www.anthropic.com/news/series-h)
```
